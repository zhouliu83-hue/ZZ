# ZZ — 周正商业技能包

周正商业的诊断工具集。

## 技能列表

| 技能 | 命令 | 说明 |
|------|------|------|
| 商业模式诊断 | `/zz-diagnosis` | 问诊/体检两种模式，消解商业问题 |
| 奥派聊天室 | `/zz-chatroom-austrian` | 哈耶克 × 米塞斯 × Claude 三人对话 |

## 使用方式

```bash
# 克隆到本地
git clone https://github.com/zhouliu83-hue/ZZ.git

# 安装技能
npx skills install ./ZZ
```
